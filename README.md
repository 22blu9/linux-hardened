# linux-hardened
This is Linux for an AMD/ARM (aarch64) computer; under dispute as of the moment, and it's hardened, bloat-free, and secure.
It will use Flatpak, and have its own repo alongside the default: 22blu9/flatpak-linux
It will contain no bloat: hardened Firefox, bare-minimal XFCE, and ZSH.
It'll have compatibility for (AMD/ARM), because Intel is inferior.
